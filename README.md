# Onzen Flat Keychain — เวอร์ชันเว็บ (iPad / Mac / Windows)

โปรแกรมเดียวกับตัว Windows แต่เปิดในเบราว์เซอร์ได้ (Safari บน iPad และ Mac, Chrome, Edge)

## วิธีเปิด

### A. เปิดจากคอมในบ้าน (ไม่ต้องขึ้นเว็บ)
1. บนคอม Windows หรือ Mac ให้ดับเบิลคลิก `serve.py` หรือรัน `python serve.py` (บน Mac ใช้ `python3 serve.py`)
2. คอมเครื่องนั้นเปิด `http://localhost:8765` ได้เลย
3. iPad ที่ต่อ Wi-Fi วงเดียวกัน เปิดลิงก์ "ในวง Wi-Fi" ที่แสดงในหน้าต่าง เช่น `http://192.168.1.20:8765`
   - ครั้งแรก Windows อาจถามเรื่อง Firewall ให้กด Allow (Private network)
   - ต้องเปิดคอมและ `serve.py` ทิ้งไว้ตลอดที่ใช้งานบน iPad

### B. ขึ้นเว็บ (ใช้ที่ไหนก็ได้ ไม่ต้องเปิดคอม)
อัปโหลดทั้งโฟลเดอร์นี้ (รวม `node_modules`) ขึ้นเว็บโฮสต์แบบไฟล์ธรรมดา เช่น Netlify Drop, Cloudflare Pages, GitHub Pages
หรือโฮสต์เดียวกับเว็บ KeychainShop ก็ได้ ไม่ต้อง build อะไรเพิ่ม
- **ข้อควรระวัง:** ถ้าเปิดเป็นสาธารณะ ใครมีลิงก์ก็ใช้โปรแกรมได้
- บน iPad กดปุ่ม Share → "เพิ่มไปยังหน้าจอโฮม" แล้วจะเปิดเหมือนแอป

### เปลี่ยนชุดฟอนต์
ลบไฟล์ใน `fonts/` แล้วใส่ฟอนต์ใหม่ พร้อมแก้ `fonts/fonts.json` (รายการ `family` = ชื่อที่โชว์ในโปรแกรม, `file` = ชื่อไฟล์)

## ไฟล์
- `web-api.js`: ทำหน้าที่แทน `window.api` ของ Electron (main.js + preload.js) ด้วยความสามารถของเบราว์เซอร์
- `web-menu.js`: แถบเมนูด้านบน + คีย์ลัด
- `web-send.js`: เมนู "ส่งไปที่" ในการ์ด Export (บันทึก / แชร์ / Bambu Studio / OrcaSlicer)
- `fonts/`: ฟอนต์ร้าน + `fonts.json`
- `serve.py`: เซิร์ฟเวอร์เล็กๆ สำหรับเปิดในบ้าน
- `index.html`, `src/`, `assets/`, `vendor/`, `node_modules/` (เฉพาะ three + manifold-3d): ดึงมาจากตัว Windows ที่ build แล้ว (app.asar)
  - แก้จากเดิมใน `src/app.js` (ค้นคำว่า `web:` — รวมแถบปรับความสูงในจอ) และเพิ่ม 3 script ใน `index.html`

## เมื่อแก้ซอร์สตัว Windows (FlatKeychain)
คัดลอก `src/*.js`, `index.html`, `assets/`, `vendor/` ที่แก้แล้วมาทับในโฟลเดอร์นี้ แล้วใส่ 2 จุดที่ระบุไว้ข้างบนกลับเข้าไป
(หรือจะย้าย 2 จุดนั้นไปไว้ในซอร์สหลักเลยก็ได้ เพราะไม่กระทบตัว Windows: ใช้ `window.api.finishFolder` และ `onFontsChanged` เฉพาะตอนที่มีฟังก์ชันนี้)
